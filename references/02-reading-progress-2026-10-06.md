## 4. 本轮已经建立的原理链

### 偏振相移链

正交偏振的参考光和测试光合束 → 四分之一波片改变偏振状态 → 不同方向检偏片产生不同相移的干涉光强 → 同时记录四幅图 → 恢复待测相位。

第 1 节详细推导见[复习文档](../docs/theory/07-polarization-phase-shifting-detailed-review.tex)。该文档只覆盖第 1 节；光栅、两套实际光路、实验及式（9）–（10）见[全文总结](guided-reading/05-qian-2001-realtime-polarization-phase-shifting.md)。

### 光栅空间分光链

在本次解释采用的均匀、单色、垂直入射平面波模型下：厚度沿 x 周期变化 → 厚薄光程差为 (n₀−1)h → 透射相位周期变化 → 将透射光场分解为空间傅里叶分量 → 满足传播条件的分量对应不同衍射方向 → 选择厚薄相差 π，使零级消失 → 一级获得主要能量 → 正交光栅形成四个主要二维通道。

这条链描述空间分光。测量所需的四种相移来自波片与检偏片配置；实际元件衔接已在第 3、4 节核对。图 3 与图 5 的光栅、波片、透镜顺序不同，不能用同一示意链替代原图。

### 散斑位移测量链

普通分光 → 两个物体产生散斑场 → 两支路偏振片选出正交分量 → 合束与四通道采集 → 变形前后图绝对值相减 → 条纹低通 → 四步恢复相位 → 相位中值滤波。前后图的相关性、相位零点和滤波近似必须保留；图 6 不能当成带完整位移标尺的精度验证。

## 5. 疑问重点与必须保留的修正

| 疑问或易混点 | 统一解释 |
|---|---|
| 传播方向与电场方向 | z 为选定的法线传播方向，x、y 为横向坐标；电场振动方向与光的传播方向分开理解。图 2 未画入射箭头，从下向上是本次示意选择。 |
| 厚薄光程为什么不同 | 比较同一入射平面至同一出射平面：厚区走材料 h₀+h，薄区走材料 h₀ 与空气 h。 |
| 复振幅不同是否意味着光强不同 | 理想相位光栅可保持振幅大小相同，只改变相位，因此刚透射时光强可均匀而复振幅周期变化。 |
| aₘ 为什么不随 x 周期变化 | E₀(x) 是位置函数；aₘ 是第 m 个空间分量的固定复系数。x 的变化由指数函数承担。 |
| 傅里叶编号为何对应衍射级次 | 对均匀平面波入射，各项的横向波矢 kₓ=2πm/p；结合波动传播关系得到 sinθₘ=mλ/p。 |
| 数学分量是否都是真实远场光束 | 满足传播条件的分量对应可观察的衍射方向；高空间频率分量可能为倏逝分量。有限光束和有限光栅带来角宽。 |
| 厚薄透射率为何满足 T厚=−T薄 | T厚=T薄 exp[ik(n₀−1)h]，作者选择该指数为 −1。T 严格为复透射率；同样的入射场乘上它后，透射复振幅也满足相反关系。 |
| 零级和非零偶数级消失的原因 | 零级消失需要厚薄相差 π；非零偶数级系数为零来自 50% 宽度结构的正弦因子。 |
| 正交光栅是不是两片先后通过 | 原文图 3 将其画成一个光栅元件。两个正交方向的作用是解释模型，不能据此认定实际有两片分立光栅或确定其制造结构。 |
| 为什么有两个约 80% | 理想可分离模型中，两个空间方向分别取正负一级的能量占比相乘；不是两次吸收损耗。 |
| 四个通道是什么方向 | 主要通道为 (mₓ,mᵧ)=(±1,±1)，向前斜向传播，分量刚出光栅时仍在空间中叠加。 |
| 原文的约 64% 与精算值 | 原文沿用约 80% 得到 0.8²≈64%；理想模型的 (8/π²)²≈65.7%。不作为实际器件效率或项目性能承诺。 |
| 偏振分束器在哪 | 图 3 用偏振分束器产生两支路；图 5 用普通分光镜，物体散射后分别放偏振片选取正交分量。 |
| 像方远心是否所有光线平行 | 像方主光线平行，其他光线仍会聚；降低像面轴向移动引起的尺度变化，不保证离焦不模糊。 |
| 变形前四个偏振片都为 0 | 这是共同基线设置，不表示初始散斑相位为零；对本文差分方法的理由为补充解释。 |
| 相减是否直接去掉随机相位 | 否。绝对差仍含散斑调制，经局部平均近似留下位移相关包络。 |
| 式（9）是否已完整证明 | 否。补充模型经绝对差、局部平均、直流与基频近似解释其形式；原文未给出足够滤波与谐波条件。 |
| 负基频系数怎样处理 | 正调制度约定需统一共同 π 偏置和相位零点，不能直接令恢复相位等于原始位移相位。 |
| 低通与中值滤波是否同一步 | 否。前者处理相关条纹，后者处理计算相位。 |

第 2 节中的 I₁、I₃、I₅ 是衍射级次的光强编号，第 1 节 I₁–I₄ 是四幅相移图的编号，后续不得混用。

## 6. 是否偏离科研目标

**主题没有偏离，讲解节奏需要保持修正后的方式。**本篇提供“空间分光 + 偏振移相 + 单次同步采集”的完整实例，服务于项目的同步动态干涉理解。傅里叶与衍射基础讨论已经回接到式（4）–（8），目前不扩展独立的傅里叶课程。

本篇实验是马赫–曾德尔与散斑干涉，不是泰曼–格林面形测量装置。阅读目的首先是读通采集链和实验依据；泰曼–格林实现放在阶段 3 的指定论文。液体折射率变化和固体离面位移也不能直接等同于平面镜面形或镜面测量相干噪声。

现有同步仿真仍是理想基线，文献阅读没有增加真实实验数据或验证硬件精度。两套文献实验已经带读；未给出的曝光、帧间时间、滤波参数、标定、效率和精度不能自行补齐或作为项目目标值。
