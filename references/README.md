# 文献阅读说明

## 目录结构

```text
references/
├─ guided-reading/   学习者逐篇阅读、回答问题并完成总结后的正式笔记
└─ ai-preread/       AI 预读初稿，仅作资料索引和候选解释
```

论文全文不提交到仓库；此处只保存阅读笔记、公开链接和项目相关判断。
