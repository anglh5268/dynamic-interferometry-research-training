## 目标和起点

近期目标：能够亲手建立、检查和解释基础光学模型，完成一次与干涉测量有关的参数对照，并形成可以向师姐展示、请求反馈的模型和记录。

已有基础包括干涉、相干、偏振相移的带读，以及静态四步和理想全局动态比较程序；这些不能替代软件操作练习。本地已有单透镜模型，参数核对见`research-log/zemax-learning-log.md`。Windows 当前模型和实际熟练程度尚未确认。

用户通过 UU 从当前设备远程操作 Windows；软件计算、模型保存均在 Windows。AI 此刻能读取 Mac 项目文件，尚未查看 Windows 实时界面。两台设备的绝对路径不互换使用。

## 成果与验收

1. 用户独立建立并保存一个简单顺序模型，解释孔径、视场、波长、表面和介质。
2. 保留一个基准模型和一个只改变指定参数的对照模型，检查解算是否引入额外变化。
3. 对照记录包含 Layout、相关分析设置、至少三个参数取值的结果和用户自己的解释。
4. 完成一个平面测试镜往返光路练习，明确其对应简化干涉仪的哪一部分；根据可用功能进一步比较参考与测试光路。
5. 最终留下模型、参数表、对照图、1–2 页说明，以及向师姐确认实际光路和任务的 2–3 个问题。

阶段成果作为学习和反馈材料，不预设为完整实验仪器或论文成果。

## 分阶段路线

按每次 30–60 分钟估计，共约 8–10 次；实际按用户操作和理解推进。两周作为第一轮检查节点，一个月作为反馈和后续任务节点。

| 阶段 | 建议次数 | 具体练习 | 进入下一阶段的依据 |
|---|---:|---|---|
| 1. 恢复并独立建模 | 1–2 | 确认版本、Edition 和文件；在已有单透镜上认识 System Explorer、Lens Data Editor、Layout；再从空白工程独立重建一次 | 能把参数表还原成光路，保存后重新打开 |
| 2. 焦点和几何像差 | 2 | 固定镜片与解算条件，只改变像面距离；比较至少三个位置的 Layout 和 Spot Diagram；再单独改变孔径，讨论视场 | 能说明焦距与后焦距、离焦与剩余像差；理解点列图 RMS 的单位和条件 |
| 3. 波前与 OPD | 1–2 | 使用同一模型、同一波长和采样；比较基准及离焦情况下的 OPD Fan / Wavefront，按可用工具选取 | 能说明参照波前、瞳坐标、waves 与长度单位，以及 OPD 和相位的联系 |
| 4. 反射与往返 | 2 | 先建立简单平面镜往返，再使用 Coordinate Break 建立折叠路径；分别改变位移和倾角 | 能解释传播方向、坐标与 Thickness 的符号，核对实际路径和光程变化 |
| 5. 干涉项目练习与汇报 | 2 | 比较简化参考/测试光路，选一个可控误差做对照；连接已有 Python 相位模型并整理成果 | 能区分几何路径、两路光程/波前差、干涉强度；能说明自己的操作与模型条件 |

单透镜阶段集中掌握必要内容后进入反射练习；复杂优化、完整公差、自由曲面、照明、杂散光和 API 暂不加入主线。

## 版本分支

官方 Student 页面明确不支持非顺序模式和 ZPL/ZOS-API；当前用户 Edition 需以 Windows 界面核对。

- 若为 Student：以顺序模式完成主线，参考和测试路径可分别建立，统一起止基准后比较光程。是否使用多重结构和内置干涉图工具，依据当前功能和建模条件确认。
- 若许可证支持非顺序：在完成主线基础后，可增加分光、双臂和相干探测练习。官方样例 A Simple Interferometer 用作操作参考；其具体结构不自动等同于目标泰曼–格林系统。

顺序模式波前分析常相对于参照波前；两个模型各自的波前图不能直接相减并宣称为两臂干涉 OPD。需先统一观察位置、坐标、采样、参照及整体光程偏置。轴向移动带来的整体相位可能在去除 piston 的图中消失，因此往返位移练习同时检查实际光程。

## 与 Python 的连接

先完成静态几何、光程和波前检查，再引入时间函数。第一次只使用理想平面镜轴向位移：明确空气中、近法向入射等条件和位移符号，核对往返光程变化；由 Python 生成时间相位和相移强度。导出二维波前时另行核对瞳面到探测面的坐标映射、倍率、单位、有效区和相位基准。

点列图 RMS 不直接作为相位误差；理想解调精度不当作仪器精度。

## UU 远程教学方式

每次先解释一个物理场景，再给 2–3 个操作；关键节点根据用户截图核对。优先普通点击和明确参数输入；快捷键需确认远程端响应。初期使用二维 Layout 阅读传播，三维用于确认折叠方向。

每次练习先保留原模型，再另存对照版本。截图优先保留分析标题、单位、数值和设置。Windows 保存位置确认后才记录真实路径，不预先指定 Mac 路径。学习结束将用户操作、结论与 AI 补充分别写入学习日志。
