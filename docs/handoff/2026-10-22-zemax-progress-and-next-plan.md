# 截至 2026-10-22 的学习盘点与下一阶段计划

本计划依据当前项目文件、既有结果及本对话截图制定。它更新 2026-10-14 的教学节奏，目标是让 Zemax 建模服务于动态干涉研究，并把软件设置、物理过程和现有相位程序连接起来。没有在本次规划中运行 Windows Zemax、重新运行仿真或验证真实仪器精度。

## 一、学习需求与当前判断

用户是 Zemax 初学者，需要先理解元件、参数、坐标和图表的物理意义，再操作软件；希望每次学习有清晰问题和可见成果，避免重复确认、细碎点击和频繁另存。项目研究方向是动态干涉测量、同步偏振相移及误差分析。

现阶段的瓶颈是知识没有连成可独立使用的流程。已有软件练习和理论、代码基础，继续从零生成理想四步图会重复已有工作。下一阶段重点为：把具体光路参数转换成相位模型中的参数，解释所得图像，随后研究一个新增的非理想因素。

## 三、值得保留的结果及纠正

1. 缩小单透镜孔径、移动像面能改变光斑，但几何 RMS 不等于相位测量误差。Quick Focus 那次显示的 Chief Ray RMS 略变差，不记为最佳焦面。
2. 平面镜倾斜 0.1°，返回方向偏转 0.2°；102 mm 返回距离给出约 0.356048 mm 的偏移。这个关系已验证，无需反复扫描确认。
3. Real Ray Trace 中 Coordinate Break 的坐标变换必须纳入阅读。默认近轴追迹忽略 Coordinate Break 的倾斜/偏心，所以近轴结果不变不能简单解释为角度小。
4. 单束相对于参考的波前误差图与两束光的光程差是不同对象；去除 piston、tilt 的操作可能移去干涉测量所需的信息。
5. 内置 Interferogram 的 X/Y-Tilt 是附加条纹倾斜参数；镜面实际倾斜是几何模型参数，两者须通过明确坐标和标定关系联系。
6. 已存动态示例的波长为 632.8 nm、相位振幅 1 rad、振动频率约 166.7 Hz、帧间隔 1 ms。保存结果中顺序法相位 RMSE≈0.2637 rad，反射面等效高度 RMSE≈13.28 nm，理想同步法接近浮点数值误差。该结果是特定理想模型的内部验证，不是实验性能，本次没有复跑。

## 四、后续主线及成果标准

预期用 4–5 次课完成第一轮，每次约 45–60 分钟，按理解和实际操作调整。次数是安排估计，成果决定是否结束该环节；界面故障不得吞掉整节学习。最先在第 1–2 次课产生一个完整衔接结果。

### 第 1 次：完整光学场景与模型边界

**问题：现在的平面镜究竟属于干涉仪哪一段，参考光怎样与它比较？**

- 教学前准备一张简化泰曼–格林光路示意图：光源/准直、分束、参考镜、测试镜、合束、观察/成像。先追两束光的完整路线，说明各元件功能。
- 把现有往返模型对应到其中一臂。建立参考/测试两路参数表，明确共同参考截面、坐标、波长、观察位置和光程差正负号。固定参考臂后，只改变测试臂。
- 基础主线使用顺序模式分路计算。完整布局图、分路顺序模型和实际同时传播的双臂装置各自标明，不用独立的两张波前图冒充已对齐的双臂结果。
- 近期优先建立标量参数接口：固定参考下的 ΔOPD。二维波前导入须另核对瞳映射、倍率、有效区和相位参考，不作为第一节完成条件。

**成果：**一张能逐段解释的系统图、一张路径/参数对照表，以及当前软件模型的明确用途。图和表由 AI 先准备，用户主要做理解与关键操作。

### 第 2 次：位移、波前与条纹的衔接

**问题：改变一个光学参数，干涉图和恢复结果为什么变化？**

- 复用已有四步/Jones 程序，增加有单位的光路参数输入。先在近法向空气双程条件下用 ΔOPD≈2d、Δφ=2πΔOPD/λ，验证镜面轴向位移的作用。
- 初始只做静态位移，选择使相位变化易于判断的少数点。验收零位移、半周期亮暗互换、整周期复原；保持初始相位和光强约定可追踪。
- 原反射练习用 550 nm，既有程序用 632.8 nm；衔接练习统一为 632.8 nm，并相应重算位移，不能混用历史数值。此时 λ/4=158.2 nm 对应 π，相位整周期的镜面位移为 λ/2=316.4 nm。
- 完成轴向位移后，才用一个小倾角对照解释空间相位梯度。倾斜平面波的关系基于共同观察平面，不把截断的回光或错位的光瞳自动当作有效干涉。
- Zemax 提供几何、路径与静态波前信息；Python 使用这些明确定义的输入计算光强和解调。结果注明几何验证、解析假设与数值处理各自的来源。

**成果：**参数设置→光程差→相位→强度图→恢复相位/相对位移的一套对照。相位只能确定模 2π 的信息；位移范围、零点或展开条件须注明，不能宣称无条件恢复绝对距离。

### 第 3 次：读懂并使用已有动态基线

**问题：为什么同一表面在运动时，顺序四步会恢复错误？**

- 直接复用现有整体正弦动态结果，解释 H（位移振幅）、f（振动频率）、Δt（帧间隔）、β（初相）与程序中 α、q 的对应。
- 用户选择一个物理参数，先预测趋势，再改一个值并检查顺序/同步对照。相位振幅与频率均不能只作为无单位滑块。
- 两种方法统一与中心时刻真值比较；保留圆周误差、相位整体偏差和去均值形状误差，避免任意 piston 对齐掩盖动态偏差。

**成果：**能解释的一张真值/恢复/误差图和一条参数曲线。程序不是本次新建的研究成果；完成的是物理解释和基线复核。

### 第 4–5 次：只增加一个新研究因素——有限曝光

**问题：四通道同时采集后，曝光期间仍在运动，会发生什么？**

- 在已有动态模型上先仅加入曝光时间积分，保持理想偏振、通道增益和空间配准。
- 比较瞬时同步结果与有限曝光同步结果。分别看调制度、相位偏差及可用区域，不预设所有运动都必然产生同样的相位偏差。
- 按曝光起止时刻积分强度，并统一曝光中心时刻；不能直接用平均相位代替平均光强。
- 检查 T→0 回到瞬时基线、静态场不受时间积分影响，以及时间积分采样加密后的收敛性。误差只按本次设定条件解释。

**成果：**曝光时间对照图、相位/等效高度误差曲线和一页适用条件说明，能够回答“同步采集解决了什么，哪些动态效应仍存在”。

选择有限曝光作为首个新增因素，是因为它直接连接实际相机与动态测量，并可复用整体运动模型。原笔记列出的局部高斯动态形变保留在下一阶段；本次顺序调整不把它记为已完成。

## 五、第一轮之后再推进的内容

依据这一轮结果和实际实验条件，按顺序选择：局部动态形变；四子图的配准/增益/相移误差；真实微偏振 2×2 马赛克的空间采样。四幅完整同位置通道与真实像素马赛克须分别建模。

指定文献路线保留，围绕当前问题选读相应章节，不在此对话重复全文带读。相干噪声、扩展源和旋转散射片专题继续按原状态暂缓。加入这些因素前，先明确实际光路、相机和原始数据来源；尚未落实的硬件参数不填成“实测值”。

## 六、授课与节奏规则

1. 每节先说明一个物理问题、预期图像和完成成果，再解释相关英文和 2–3 个核心参数，然后操作。
2. 每次只改一个因素；一个基准、一个有意义的对照和解释一致后即推进，不机械要求三个取值或反复截图。
3. 正常结束时保存当前命名模型；结构明显改变时才另存必要版本。取消旧计划每次练习都另存对照版本的默认要求。
4. 不用连续基础测验作为前进门槛；用用户对当前图的解释和一次自主修改判断理解，并及时补缺。
5. AI 提前准备结构图、参数含义、计算数量级与已验证的操作入口。找不到按钮时核对一次界面后换可行路径；概念和已有数据分析继续推进。
6. 只在关键节点截图；已核对的文件身份、单位和设置仅在换文件或相关改动时重查。
7. 每节结束记录新能力、新证据和未决项。代码运行成功不等于用户已会解释，数值自洽不等于仪器准确度。

## 七、软件能力与计算边界

此前截图为 Student。当前官方说明仍列出 Student 不支持非顺序及 ZPL/ZOS-API；本计划因此使用顺序模式与人工参数传递，不依赖许可证升级或 API 自动联动。若许可证有变化，再核对一次。

官方内置 Interferogram 可比较两个配置的瞳波前，但默认假定出瞳完全重叠，忽略横向错位、倍率差和透过率差。整体光程相位还受 Consider Path Length Difference 与参考选择影响。因此不能用它单独证明实际相机上的双束重合和真实对比度，也不能把“Reference”当作已构建的实体参考臂。首次衔接优先传递差分光程，避免整体相位基准丢失。
