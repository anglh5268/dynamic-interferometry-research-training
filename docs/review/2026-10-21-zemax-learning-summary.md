## 1. 建立的物理模型

文件名为 `plane_mirror_round_trip.zmx`。最后的光线报告显示 Windows 路径：
`C:\Users\86156\Documents\Zemax\Samples\plane_mirror_round_trip.zmx`。

系统使用顺序模式、毫米单位、0.550 μm 波长、轴上入射和 10 mm 入瞳直径。光束从起始面出发，传播到平面反射镜，再返回起始面所在的观察平面。它是基础反射练习，还没有分光镜、参考臂和测量臂。

倾斜前 Lens Data 的对应关系：

| 行 | 含义 | 关键设置 |
|---|---|---|
| 0 OBJECT | 无穷远物体，提供平行入射光 | Thickness = Infinity |
| 1 STOP | 光阑及起始参考面 | Thickness = +102 mm |
| 2 Standard | 平面反射镜 | Radius = Infinity，Material = MIRROR，Thickness = −102 mm |
| 3 IMAGE | 返回光的观察面 | 与起始面处于同一轴向位置 |

Radius 的 Infinity 表示曲率半径无限大，即平面。Thickness 表示当前面到下一面的轴向间隔；反射后的负值与返回传播的符号约定有关，不是负的实际路程。IMAGE 是计算终止和观察的位置，不意味着这里一定形成聚焦像。

## 2. 验证的数值

| 状态 | PLEN 总光程 | 返回结果 |
|---|---:|---|
| 镜面距离 101 mm，垂直入射 | 202.000 mm | 沿原路返回 |
| 镜面距离 102 mm，垂直入射 | 204.000 mm | 沿原路返回 |
| 镜面距离 102 mm，Tilt X = 0.1° | 204.001 mm（界面舍入） | 返回面 Y = +0.356048 mm |

正常入射、空气近似折射率 1 时，总光程约为两倍镜面距离。镜子沿轴移动 1 mm，往返总光程增加约 2 mm。

PLEN 的 Surf1、Surf2 选择测量的起止面，Value 是实际计算结果；Target 是优化目标，Weight 是优化权重。Weight = 0 时仍可读取计算后的 Value，因此顶部 Merit Function = 0 不表示光程为零。

## 3. 倾斜镜面后，表格为什么增加两行

Tilt/Decenter 工具在镜面前后加入 Coordinate Break：

| 当前行号 | 含义 |
|---|---|
| 1 | STOP 起始面 |
| 2 | Coordinate Break：进入倾斜的局部坐标系 |
| 3 | MIRROR：真正发生反射的表面 |
| 4 | Coordinate Break：恢复后续坐标系 |
| 5 | IMAGE：返回观察面 |

Coordinate Break 定义坐标位置和方向，本身不是新增的实体光学元件。插入后 PLEN 的终止面已经改为 5。观察面自动半口径增至约 5.356 mm，是为了包含偏移后的光束，反射镜半口径仍为 5 mm。

镜面倾斜 0.1°，反射返回方向相对原返回方向偏转 0.2°。对于当前几何配置：

\[
|\Delta y|=102\tan(0.2^\circ)\approx0.356048\ \mathrm{mm}.
\]

该数值与真实光线追迹相符。往返路程约为

\[
L=102+\frac{102}{\cos(0.2^\circ)}\approx204.000621\ \mathrm{mm},
\]

所以界面显示 204.001 mm。镜面倾斜既改变返回位置，也使返回段稍微变长。

## 4. Single Ray Trace 各类数据的关系

| 英文 | 含义及本次阅读要点 |
|---|---|
| Hx、Hy | 归一化视场坐标，选择从哪个物点或入射方向来的光束 |
| Px、Py | 归一化入瞳坐标，选择该光束中的一条光线；本次最终均为 0 |
| Real Ray Trace Data | 真实几何光线追迹，包含本次镜面倾斜的影响 |
| Paraxial Ray Trace Data | 近轴模型的计算结果，不能直接替代倾斜系统的真实追迹 |
| X/Y/Z-coordinate | 光线与当前面的交点；Local 模式下分别用各面的局部坐标表示 |
| X/Y/Z-cosine | 光线在该面作用后的方向余弦；反射系统须结合坐标和带符号的传播段读取 |
| X/Y/Z-normal | 当前交点的表面法线分量；不同面的局部表示不能直接当作同一全局方向比较 |
| Angle in | 入射光线相对表面法线的入射角；镜面行约 0.1°，观察面行约 0.2° |
| Path length | 从上一面到当前面的带符号几何传播长度，不是整条光路的累计光程 |

当前 Local 报告中的各面 Z = 0，不代表这些面在空间重合。返回段 Path length 约 −102.000621 mm，与 Y-cosine 约 −0.0034906514 配合，得到正的 Y 位移约 +0.356048 mm。不能只凭 Z-cosine 仍为 +1 附近，就判断反射镜没有起作用。

**关于近轴数据不变的纠正：**OpticStudio 默认在近轴追迹中忽略 Coordinate Break 引入的倾斜和偏心，使用等效的居中系统。因此这里近轴结果仍为 Y = 0，不能简单解释成“角度太小被近似掉”。截图结果符合该默认行为，但本次没有直接查看对应设置复选框。[官方说明](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v251/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Ignore_Coordinate_Breaks.html)

## 5. 与干涉测量的联系及本次边界

理论上，在空气中、正常入射且参考臂固定时，镜面轴向位移 d 引起的往返光程变化约为 2d，相位变化为 Δφ ≈ 4πd/λ。λ = 0.550 μm 时，移动 λ/4 = 0.1375 μm 对应 π 相位变化；移动 λ/2 = 0.275 μm 对应一个完整周期。本次没有实际构建双臂干涉模型来观察这些相位变化。

本次完成的是在指导下建立和读懂基础反射模型，并用数值验证往返光程和反射角度加倍。后续教学应继续先说明物理场景、字段意义和预期现象，再安排少量必要操作，不重复验证已经确认的关系。
