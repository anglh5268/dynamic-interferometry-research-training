# 泰曼–格林相干噪声抑制：首轮比较方案

> 状态：依据现有文献形成的**待实验验证方案**，不是已搭建光路或已取得的性能结果。器材、被测件和精度指标尚未确定，首个验证对象暂选平面镜。

## 1. 光路功能块与三种光源条件

```text
同一激光器 ─ 光源模块 ─ 线偏振片/半波片 ─ 偏振分束器
                                           ├─ 参考臂：波片、参考镜
                                           └─ 测试臂：波片、平面镜
                    合束 ─ 相机前波片/像素相移掩模 ─ 相机
```

物光和参考光的偏振编码参考 [Novak 等的泰曼–格林系统](../../references/guided-reading/02-novak-2005-micropolarizer.md)与 [North-Morris 等图 1](https://www.researchgate.net/publication/228459102_Noise_reduction_in_dynamic_interferometry_measurements)。单帧相位编码负责时间同步；光源模块负责控制空间相干性及散斑。实际器件选择前须用 Jones 矩阵核对波片方向、双程偏振变化及四通道相移符号。

| 条件 | 光源模块 | 主要判别 |
|---|---|---|
| A：有效点源 | 单模光纤输出 | 保留现有高空间相干条件，作为寄生条纹和重复性基准。 |
| B：扩展源 | 同一激光器接多模光纤，散射片静止，纤芯和成像几何固定 | 判断光源空间范围对寄生条纹与目标条纹的共同作用，并暴露静态模态散斑。 |
| C：扩展源加动态散斑抑制 | 与 B 相同的多模光纤及几何，仅令散射片旋转 | 单独观察曝光内散斑平均的收益与条纹模糊代价。 |

B 是本项目拟做的消融条件；[North-Morris 等（2010）](https://doi.org/10.1117/12.860450)的点/扩展源对照和[胡晨辉等（2022）](https://www.researching.cn/ArticlePdf/m00006/2022/42/19/1906001.pdf)的无/有旋转毛玻璃对照提供依据。三条件应保持相机增益、光圈、ROI、被测件姿态及可比较的曝光/光子计数；光功率变化要记录，不能把光强差当作降噪。

## 2. 各方法的预计收益和限制

| 方法 | 有助于抑制 | 需要付出的代价或校验 |
|---|---|---|
| 单帧偏振相移 | 顺序四帧间的动态相移不一致 | `2×2` 像素错位、通道响应、有限曝光与偏振误差；见已读 [Novak](../../references/guided-reading/02-novak-2005-micropolarizer.md)。 |
| 多模光纤扩展源 | 有空间剪切的寄生干涉与部分固定伪影 | 目标条纹可见度可能下降，光纤本身引入模态散斑；须核对泰曼–格林共轭面和目标 OPD。 |
| 旋转散射片 | 曝光内变化的散斑图样 | 曝光过短时独立散斑数不足；曝光过长时动态目标变模糊；还需隔离转动机构振动。 |
| 宽谱扩展源候选 | 某些非目标光程的寄生干涉 | 双臂光程与玻璃厚度匹配要求需待 [Zhou 等（2025）](https://doi.org/10.1364/AO.541924)全文核对后设计。 |
| 算法校准 | 通道偏振/强度差、配准和部分可辨认伪影 | 应使用原始通道数据与光学基线比较，不能把平滑后的表面当作真实面形。 |

## 3. 与现有仿真衔接的最小前向模型

现有 `φ(x,y,t)` 与理想同步四通道保留为时间采样基线。下一独立模型按**每个光源点的光强**求和，再对曝光时间积分；每个光源点内的参考、测试和寄生场才相干相加：

$$
I_k(x,y)=\frac{1}{T}\int_{t_0}^{t_0+T}\!\int_{\mathcal S}
w(s,t)\left|P_k\big[E_r(x,y;s,t)+E_t(x,y;s,t)+E_g(x,y;s,t)\big]\right|^2\,ds\,dt+n_k.
$$

`s` 表示光源位置或照明角度，`w` 是归一化非负权重，`P_k` 是四个检偏通道，`E_g` 是一个可开关的寄生场。此式是**本项目拟用的建模框架**，并非逐字复现某篇论文。优先做两种单因素验证：关闭 `E_g` 时点源应回到现有理想基线；固定时间和通道条件后，逐步改变光源范围及寄生场。散斑应由具有明确空间/时间相关性的随机实现产生，不能直接叠加独立像素白噪声并称为相干噪声。真实微偏振马赛克再作为后续独立采样层加入。

## 4. 实验和数据评价

1. **静态平面镜**：每个条件记录原始四通道、暗场和重复单帧结果；先确认目标条纹仍可解调，调整物/参考光强匹配并记录光源有效大小。
2. **噪声拆分**：在同一 ROI 报告目标条纹可见度 `V=(I_max-I_min)/(I_max+I_min)`；在去除缓慢照明梯度的背景图上报散斑对比度 `K=σ_I/〈I〉`；在恢复相位上报告伪影空间谱及重复测量差的 RMS。没有独立标准面形时称“重复性”，不称“绝对准确度”。
3. **短曝光检查**：对 B 与 C 扫描曝光时间；每个曝光点同时报告 `K`、`V`、相位重复性和可用像素比例。若之后加入受控运动，再记录目标运动幅度与频率，并把瞬态相位偏差和曝光模糊单列。
4. **结果判据**：C 相对 B 降低散斑的同时，目标可见度和有效像素比例仍满足相位解调；B 相对 A 降低寄生伪影时，目标条纹的对比度损失需被量化。所有“改善倍数”注明是单帧、重复平均还是频带内指标。

论文中的 `600 μm` 光源、`0.52～1.70 mm` 纤芯、`5 ms` 曝光与改善倍数均不设为本项目验收阈值。实际参数应由所选镜面、工作波长、准直/成像几何、相机和可用光源确定。
