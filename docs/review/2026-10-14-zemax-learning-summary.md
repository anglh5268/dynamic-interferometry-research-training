# Zemax 学习总结：单透镜、视场、孔径与调焦

日期：2026-10-14。软件：Ansys Zemax OpticStudio 2026 R1 Student，Sequential 顺序模式。操作方式：用户通过 UU 远程控制 Windows，AI 依据用户截图指导、解释并整理记录。

今天完成的是在已有单透镜模型上的有指导练习，包括识别光路、修改视场、固定曲率解算、孔径对照、像面位置对照和 Quick Focus 结果检查。尚未练习从空白工程独立建立模型，也没有建立完整干涉仪。

## 1. 今天的物理场景

同一个无穷远物点发来的光，在透镜处近似是一束平行光；不同物点对应不同入射方向。它们经过同一片透镜，在像面上形成不同位置的像。

模型的传播顺序为：无穷远物面 → 平面前表面 → 4 mm N-BK7 玻璃 → 曲面后表面 → 空气 → IMAGE 像面。

| 模型项目 | 今天核对的内容 |
|---|---|
| 模式、长度单位 | Sequential；mm |
| 波长 | 本地源文件 0.6328 μm；Windows 界面四舍五入显示 0.633 μm；一个活动波长 |
| 视场 | Angle；X 均为 0°；Y 原为 0°、3.5°、5°，第三行改为 2.5° |
| 前表面 | 平面，指定为 STOP；之后 4 mm N-BK7 |
| 后表面 | 本地源文件半径约 −51.509 mm；Windows 表格显示截断的 −51.5… |
| 曲率规则 | 原为 F Number 解算，F/#=4；孔径对照前改为 Fixed |
| 入瞳直径 | 基准 25 mm，对照 12.5 mm |
| 后表面到像面的距离 | 基准 100 mm；随后测试 95 mm，并做自动调焦及附近位置比较 |

一行通常代表一个光学表面，所以一片透镜由前、后两行共同描述。当前直通模型中，Thickness 是本表面到下一表面的轴向距离，Material 描述这段空间里的介质。

## 2. 三个关键变量分别控制什么

| 改动 | 实际改变的物理量 | 观察结果 |
|---|---|---|
| 第三视场 Y Angle：5° → 2.5° | 选取物点的方向、整束入射光的倾斜角 | 对应像的位置更接近轴上像点 |
| 入瞳直径：25 → 12.5 mm | 被接收光束的范围 | 光束变窄；在当前像面上，三个视场的几何光斑都明显减小 |
| 后表面到像面距离：100 → 95 mm | 观察面的位置 | 光束会聚区更接近像面，三个视场的 RMS 半径都减小 |

视场角回答“光从哪个方向来”，孔径回答“接收多宽的一束光”，像面距离回答“在哪个位置观察这些光线的落点”。

模型是一个会聚单透镜，负曲率半径表示曲率中心方向，不表示负焦距。最初状态栏显示 EFFL=100 mm；修改孔径后的完整有效焦距没有在后续截图中逐次复核。

## 4. 如何读今天的点列图

每个小十字是一条采样光线在像面上的落点。一张小图对应一个物点，三个小图对应三个视场。所有落点都已经在所选像面上，判断聚焦情况要看它们是否集中。

RMS 与 GEO 都是半径，单位 μm。1000 μm=1 mm。RMS 综合考虑所有采样落点到参考点的距离；GEO 为最远落点到参考点的距离。本次使用 Chief Ray 参考，因此两者都相对于主光线落点计算。

各小图分别围绕自身参考点显示；图框的摆放位置不是像点在相机上的实际位置。IMA 数值说明像的位置，RMS/GEO 说明这个位置附近光斑的大小。

本次 Pattern=Hexapolar、Ray Density=6，表示入瞳内使用六圈采样。经过镜片后，这些采样点映射到像面，可以排列成大小不同、偏移或交叠的圈。圈状排列不是多个物点，也不能直接当作衍射环或干涉条纹；仅凭圈大小不能确定光线来自哪个入瞳半径。

Layout 与 Spot Diagram 的颜色取决于各自着色设置。本次 Layout 区分视场，Spot Diagram 按波长着色；只有一个波长，所以点列图各视场均为同一种颜色。

## 5. 实际对照结果

### 5.1 孔径对照：像面距离保持 100 mm

镜片曲率先固定，再改变入瞳直径。两张设置截图均确认：Hexapolar、Ray Density=6、Chief Ray、全部视场/波长、Image 表面。

| 视场角 | 25 mm 入瞳 RMS / μm | 12.5 mm 入瞳 RMS / μm | RMS 缩小倍数 |
|---|---:|---:|---:|
| 0° | 562.738 | 66.424 | 8.47 |
| 3.5° | 649.544 | 101.091 | 6.43 |
| 2.5° | 607.794 | 85.020 | 7.15 |

结论：在当前像面与分析条件下，缩小入瞳使几何落点更集中。定性解释是减少了通过镜片边缘区域的光线；本次未分离球差、离焦和其他像差的具体贡献。最佳孔径仍需兼顾衍射与通光量。

两图采用自动尺度：25 mm 图为 4000 μm，12.5 mm 图为 1000 μm，不能直接按屏幕大小比较。

### 5.2 像面位置对照：入瞳保持 25 mm

下表按相同点列图参考条件整理；后续位置截图没有逐次展开所有采样设置，依据用户保持设置的操作流程记录。

| 后表面到像面距离 / mm | 0° RMS / μm | 3.5° RMS / μm | 2.5° RMS / μm |
|---|---:|---:|---:|
| 100 | 562.738 | 649.544 | 607.794 |
| 95 | 184.001 | 291.307 | 243.019 |
| Quick Focus，约 95.103 | 186.311 | 294.579 | 245.871 |
| 第一张扫描图，按流程预计 94.5 | 180.702 | 280.206 | 235.042 |
| 第二张扫描图，按流程预计 95.5 | 199.957 | 310.127 | 260.426 |

94.5 / 95.5 两张扫描截图没有显示 Thickness，也未由用户文字标注，距离按要求的操作顺序对应，待后续读取模型核对。其余表内 RMS 数值均为实际截图读数。

结论：100 → 95 mm 后明显改善；在三个附近位置中，第一张扫描图三个视场的 RMS 都最小。若距离映射与操作顺序一致，则 94.5 mm 是这些测试位置中较好的位置，尚未验证精确最佳焦点。

Total Axial Length 从 104 mm 变成 99 mm，是 4+100 → 4+95 的结果，描述空间布置变化；它不是焦距，也不是包含折射率加权的光程。

### 5.3 Quick Focus 的保留结果

实际确认的设置为 Spot Size Radial、Use Centroid 未勾选。第 2 行 Thickness 显示约 95.103 mm；Layout 总长为 99.10258 mm。

与 95 mm 基准相比，三个 Chief Ray RMS 都增大约 1.1%–1.3%。这次自动调焦结果不能记作改善，也不能当作已验证最佳焦面。参考点设置没有明显选错；内部采样差异等原因尚未确认，保留结果，不编造原因。

## 6. 为什么先固定 F 数解算

当前空气中无穷远成像的近轴关系为 N=f/D。初始有效焦距约 100 mm、入瞳直径 25 mm，对应 N=4。

后表面原带 F Number 解算，软件会改变曲率以满足 F 数条件。若保留解算而把入瞳减半，镜片曲率、焦距也可能跟着变化。今天先将解算改为 Fixed，目的就是让孔径实验只改变指定变量。

这形成了今天最有用的操作方法：提出一个具体问题 → 固定其他条件及解算 → 改一个参数 → 用同一分析标准读取结果 → 作出有限范围内的判断。

## 8. 下次从哪里开始

下次先重新打开保存的练习模型，核对文件名、孔径、曲率解算、像面距离，尤其确认两张扫描图的距离对应关系。今天结束在手动焦面比较，没有开始 OPD 分析。

下一小目标是认识波前与 OPD：先说明同一物点经不同入瞳位置传播的光线和理想参照波前，再查看软件坐标、参考和单位，逐步连接干涉相位。点列图 RMS 不能直接当作相位误差。

继续采用“物理场景 → 英文名称与中文含义 → 一次小操作 → 结果解释”的节奏。每次参数练习先说明验证问题、控制变量和判断标准，再要求截图。
