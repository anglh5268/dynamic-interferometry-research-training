# 动态干涉测量技术科研训练

指导教师：李建欣  
研究主题：动态干涉测量技术

## 项目目标

围绕动态条件下的高精度光学表面与波前检测，学习同步偏振干涉成像机理、相位解调算法和单幅干涉图处理方法，并通过数值仿真与实验逐步验证动态波前重建能力。

## 当前研究路线

1. 补充干涉、相干、偏振与波前测量理论；
2. 使用 Python 建立双光束干涉与四步相移仿真；
3. 分析顺序采集在动态条件下的误差；
4. 研究同步偏振相移成像与非理想误差校正；
5. 尝试单幅干涉图相位解调及真实数据验证。
