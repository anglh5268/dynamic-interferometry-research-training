### 三、第 1 次课正式记录：简化泰曼–格林干涉系统架构与物理边界

#### 1. 泰曼–格林干涉仪物理架构剖析

简化泰曼–格林干涉仪（Twyman-Green Interferometer）的光路传播逻辑如下：
```text
[激光源 λ=632.8nm]
       │
       ▼
 [扩束准直透镜组] (获得平面波波前)
       │
       ▼
┌──────────────┐      参考臂 (往返)       ┌──────────────┐
│  分束棱镜 BS  │ ──────────────────────> │  参考镜 M1   │ (位置固定，L_ref)
│ (50:50 分光) │ <────────────────────── │ (平面反射镜)  │
└──────┬───────┘                         └──────────────┘
       │
       │ 测试臂 (往返)
       ▼
┌──────────────┐
│  测试镜 M2   │ (含微位移 d(t) / 表面形貌 h(x,y)，L_test = L_ref + d)
│ (被测反射件) │
└──────┬───────┘
       │ (返回光经过 BS 分束面合束)
       ▼
┌──────────────┐
│  成像物镜组  │ (将被测面 M2 共轭成像到探测器靶面)
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 探测器/相机  │ (记录双光束干涉光强分布 I(x, y, t))
└──────────────┘
```

#### 2. 原模型 `plane_mirror_round_trip.zmx` 的物理定位

- **原模型本质**：Windows 端所建模型 `plane_mirror_round_trip.zmx`（STOP $\to$ MIRROR $\to$ IMAGE），在物理上严格对应**泰曼–格林干涉仪中的单臂往返（测试臂或参考臂）**。
- **面序号与物理元件映射**：
  - **Surface 1 (STOP)**：对应分束棱镜（BS）的出射/分光基准面。
  - **Surface 1 厚度 (+102 mm)**：对应分束面到反射镜的物理距离 $L_0$。
  - **Surface 2/3 (MIRROR / Coordinate Break)**：对应测试镜 $M_2$（或参考镜 $M_1$）的物理表面；Coordinate Break 模拟镜面机械倾斜（Tilt X/Y）。
  - **Surface 3 厚度 (-102 mm)**：反射后的反向传播段，负号为 Zemax 顺序模式下的方向约定。
  - **Surface 5 (IMAGE)**：对应返回光重新汇聚于 BS 分光面的重合截面（即后续干涉合成的共同参考截面）。

#### 3. 双臂光程与相位参数对照表

统一定义工作波长 $\lambda = 632.8\,\mathrm{nm} = 0.6328\,\mu\mathrm{m}$，介质为标准空气（$n \approx 1$）：

| 参数项 | 参考臂（Reference Arm） | 测试臂（Test Arm） | 物理差值 / 干涉物理量 |
|---|---|---|---|
| **端面镜元件** | 参考平面镜 $M_1$（固定理想参考） | 被测平面镜/工件 $M_2$（含动态运动） | 相对位移 $d(t)$ 或形貌 $h(x,y)$ |
| **单程几何间距** | $L_{\mathrm{ref}} = 102.000\,\mathrm{mm}$ | $L_{\mathrm{test}} = 102.000\,\mathrm{mm} + d$ | $\Delta L = d$ |
| **往返几何光程 (OPD)** | $\mathrm{OPD}_{\mathrm{ref}} = 2 n L_{\mathrm{ref}} = 204.000\,\mathrm{mm}$ | $\mathrm{OPD}_{\mathrm{test}} = 2 n (L_{\mathrm{ref}} + d)$ | $\Delta\mathrm{OPD} = \mathrm{OPD}_{\mathrm{test}} - \mathrm{OPD}_{\mathrm{ref}} = 2 d$ |
| **波前倾角（Tilt）** | 准直对准，$\theta_{\mathrm{ref}} = 0^\circ$ | 镜面微倾斜 $\theta_x$（如测试过的 $0.1^\circ$） | 返回波前偏转 $2\theta_x$（偏转 $0.2^\circ$） |
| **干涉初相 $\phi$** | 基准相位 $\phi_{\mathrm{ref}} = 0$ | $\phi_{\mathrm{test}} = \frac{2\pi}{\lambda}\Delta\mathrm{OPD}$ | $\Delta\phi = \frac{4\pi}{\lambda} d$ |

#### 4. 关键物理量与尺度换算基准（$\lambda = 632.8\,\mathrm{nm}$）

- **双程反射光程倍增效应**：
  反射镜沿光轴位移 $d$ 时，光线经历“去程+回程”，实际波前光程差改变 $2d$。
- **条纹极值变化周期**：
  - 当镜面移动 $d = \frac{\lambda}{4} \approx 158.2\,\mathrm{nm}$ 时：
    $$\Delta\mathrm{OPD} = 2 \times 158.2\,\mathrm{nm} = 316.4\,\mathrm{nm} = \frac{\lambda}{2} \implies \Delta\phi = \pi$$
    干涉图发生**明暗条纹互换**。
  - 当镜面移动 $d = \frac{\lambda}{2} \approx 316.4\,\mathrm{nm}$ 时：
    $$\Delta\mathrm{OPD} = 2 \times 316.4\,\mathrm{nm} = 632.8\,\mathrm{nm} = \lambda \implies \Delta\phi = 2\pi$$
    干涉相位变化一个完整周期（**移动整整 1 条干涉条纹**）。
- **符号约定（Sign Convention）**：
  若测试镜沿光轴远离分束器（$d > 0$），则测试臂光程变长（$\Delta\mathrm{OPD} > 0$）。在平面波电场 $E = E_0 \exp[i(\mathbf{k}\cdot\mathbf{r} - \omega t + \phi)]$ 描述下，测试光相对于参考光相位滞后。

#### 5. Zemax Student 顺序模式与 Python 动态相位的衔接边界

- **为何不直接在 Zemax 顺序模式下做物理相干叠加？**
  1. Zemax Student 不支持非顺序模式（NSC），无法在同一物理空间中自动分束、汇合两束独立相干光线并计算波前干涉矢量叠加。
  2. Zemax 顺序模式下的自带工具 `Interferogram` 仅是在计算出口出瞳波前差异并叠加数学倾斜（Tilt），并非物理双臂干涉仪，且无法引入动态时域振动与微偏振阵列（PPM）采样。
- **确定的衔接工作模式（Zemax 几何与光程 $\to$ Python 干涉与动态解调）**：
  - **Zemax 负责**：精确提供单臂/双臂几何光程（PLEN）、反射镜姿态偏转（Coordinate Break 倾斜与落点位移）、像差与波前畸变分布 $W(x,y)$。
  - **参数导出/传递**：以光程差 $\Delta\mathrm{OPD}(x,y,t)$ 作为统一接口输入。
  - **Python 负责**：接收光学参数，进行双光束/四通道偏振干涉强度合成 $I(x,y,t)$、时变微振动注入 $d(t) = H\sin(2\pi f t + \beta)$、四步/同步偏振解调与解包裹，评估动态相移误差。

### 四、补充研讨：完整版 Zemax 的独立能力边界与「打通 Python」的物理本质

#### 1. 完整商业版 Zemax（旗舰版/企业版）能否独立实现？

**结论**：完整版 Zemax 可以**直接生成物理干涉条纹图**，但**无法独立完成干涉测量的逆向相位解调、动态振动抗扰评价与闭环误差分析**。

- **完整版 Zemax 具备的物理能力**：
  1. **非顺序模式（NSC, Non-Sequential Mode）**：允许光线在分束棱镜（BS）表面发生真正的能量物理分束（Ray Splitting），两束光沿不同路径传播后在探测器表面同时汇聚。
  2. **相干探测器（Coherent Detector）**：完整版支持追踪每条光线的复数光场振幅与光程相位 $E_k = A_k \exp(i\phi_k)$。当两束光打在同一个探测器像元上时，软件自动执行复振幅矢量相加并取模方：
     $$I(x, y) = \left| \sum_k E_k(x, y) \right|^2$$
     由此可以直接在探测器窗口看到明暗交替的干涉条纹。
  3. **偏振光追迹（Polarization Ray Tracing）**：能计算带涂层棱镜、1/4 波片、偏振分束器（PBS）的琼斯/穆勒矩阵演化。
- **完整版 Zemax 依然无法独立完成的环节（为什么必须配合算法）**：
  - **正向仿真 vs 逆向解调**：Zemax 本质是“正向光机追迹与像质评估软件”（从光源、透镜追迹到像面光强）。而干涉测量的核心是**逆向信号处理**（从探测器拍摄的 4 幅相移图或 1 幅马赛克图，反解出未知的被测波前 $\phi(x, y)$ 并解包裹）。
  - **缺少干涉解调工具链**：Zemax 没有内置四步相移反正切解调（Arctan）、空间载频傅里叶变换、二维相位解包裹（Goldstein / 最小二乘法），更无法自动给出测量残差 RMSE。
  - **动态连续振动与相机积分**：在真实动态测量中，被测镜处于高频机械微振动中 $d(t) = H \sin(2\pi f t)$，且相机探测器具有有限曝光时间 $T$（发生时间积分效应 $\int_0^T I(t) \mathrm{d}t$）。即便在工业界，这类动态时序仿真也是通过 Zemax 的编程接口（ZOS-API）把光路调用到 Python/MATLAB 中，循环控制时步并完成算法解调。

#### 2. “在 Python 中打通”究竟是指什么？

在科研训练的前期，Python 仿真（`simulation/python/`）处于“纯数学算法验证”阶段：
- 当时构造的波前是数学函数（例如 `peaks(N)`），振幅是无单位的抽象数字（例如 $\alpha = 1.0\,\mathrm{rad}$），时间步长也是理想编号。
- 这种纯数学仿真脱离了真实光学硬件：**无法回答“如果导轨抖动了 50 nm，干涉图会变成怎样？”、“如果反射镜倾斜了 0.1°，探测器上条纹间距是多少个像元？”、“如果相机曝光是 5 ms，条纹对比度下降多少？”**。

**“打通 Python”的真正含义，是建立“光学物理参数 $\to$ 探测器干涉图 $\to$ 算法恢复与误差评估”的端到端真实映射链条**：

```text
┌─────────────────────────┐
│ Zemax 光学物理参数       │
│ • 波长 λ = 632.8 nm      │
│ • 镜面微位移 d (nm)      │
│ • 倾斜角 θ (0.1°)       │
│ • 系统波前畸变 W(x, y)    │
└───────────┬─────────────┘
            │  物理参数严格映射 (ΔOPD = 2d, 偏转角 = 2θ)
            ▼
┌─────────────────────────┐
│ Python 干涉与探测引擎   │
│ • 计算物理相位差 Δφ(x,y,t)
│ • 注入时变微振动 d(t)    │
│ • 模拟相机曝光时间积分   │
│ • 模拟偏振微透镜马赛克   │
└───────────┬─────────────┘
            │  生成真实相机采集图像 I(x, y, t)
            ▼
┌─────────────────────────┐
│ Python 动态解调与评估   │
│ • 四步法 / 同步偏振解相  │
│ • 恢复被测镜面物理位移   │
│ • 与真值对比计算 RMSE (nm)
└─────────────────────────┘
```

具体落实为以下 4 个具体接口的打通：
1. **尺度单位物理化**：
   输入不再是抽象无量纲相位，而是镜面轴向运动 $d$（单位：$\mathrm{nm}$）。通过双程反射关系式精确换算：
   $$\Delta\mathrm{OPD} = 2 d \quad \implies \quad \Delta\phi = \frac{4\pi}{\lambda} d$$
2. **镜面姿态与条纹间距物理化**：
   在 Zemax 中验证了 Coordinate Break 倾斜 $0.1^\circ$ 会导致返回光偏转 $0.2^\circ$。在 Python 中，这就对应干涉图中空间载频载波的严格倾斜梯度：
   $$f_x = \frac{\sin(0.2^\circ)}{\lambda} \approx 5.51\,\mathrm{lp/mm}$$
   从而能定量计算需要多少像元尺寸的相机才能采样该干涉条纹而不发生频域混叠。
3. **真实光学像差输入**：
   Zemax 追迹出的单透镜或物镜波前误差（OPD Fan 数据或 Zernike 像差系数）可直接作为测试臂的静态系统误差 $W_{\mathrm{sys}}(x,y)$ 传入 Python，检验算法能否有效校准和扣除系统本底误差。
4. **动态与时域响应评估**：
   把真实的微振动频率（如 $f = 100\,\mathrm{Hz}$）、振幅（如 $H = 50\,\mathrm{nm}$）和相机的曝光时间（如 $T = 2\,\mathrm{ms}$）送入程序，评估传统顺序相移法为什么崩溃（条纹模糊/跳相），并量化同步偏振法在多大振动烈度下依然有效。

### 五、参数衔接与干涉仿真：全流程逻辑与预期视觉效果拆解

#### 1. 端到端实现全过程（The Process）

整个过程分为四个严格衔接的阶段：

- **阶段一：输入真实光学参数（来自 Zemax / 光路设计）**
  - 光源参数：$\lambda = 632.8\,\mathrm{nm}$。
  - 试样表面物理高度：$h(x, y)$（例如高斯台阶、微小面形缺陷或理想平面）。
  - 镜面轴向位移：$d$（纳米量级，如 $0\,\mathrm{nm}, 158.2\,\mathrm{nm}, 316.4\,\mathrm{nm}$）或时变微振动 $d(t) = H\sin(2\pi f t)$。
  - 镜面微倾斜：$\theta_x$（如 Zemax 中验证的 $0.1^\circ$ Coordinate Break 倾角，导致出射光偏转 $0.2^\circ$）。
- **阶段二：计算物理光程差与探测器干涉光强**
  - 空间总光程差：
    $$\Delta\mathrm{OPD}(x, y) = 2 \cdot [h(x, y) + d] + 2 x \sin(2\theta_x)$$
  - 波动相位差：
    $$\Delta\phi(x, y) = \frac{2\pi}{\lambda} \Delta\mathrm{OPD}(x, y) = \frac{4\pi}{\lambda}[h(x, y) + d] + 2\pi f_x x$$
  - 生成 4 幅具有标准相移 $\delta_k \in \{0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}\}$ 的相机像面干涉图：
    $$I_k(x, y) = I_0(x, y) \left[ 1 + \gamma(x, y) \cos(\Delta\phi(x, y) + \delta_k) \right]$$
- **阶段三：逆向解调与相位解包裹**
  - 提取包裹相位（Wrapped Phase）：
    $$\Delta\phi_{\mathrm{wrapped}}(x, y) = \operatorname{atan2}(I_4 - I_2, I_1 - I_3) \in (-\pi, \pi]$$
  - 空间连续解包裹（2D Phase Unwrapping）：消除 $\pm\pi$ 处的阶跃截断，恢复平滑连续相位 $\Delta\phi_{\mathrm{unwrapped}}(x, y)$。
- **阶段四：物理表面重构与误差残差评估**
  - 逆推物理表面形貌：
    $$\hat{h}(x, y) = \frac{\lambda}{4\pi} \left[ \Delta\phi_{\mathrm{unwrapped}}(x, y) - 2\pi f_x x \right] - d$$
  - 误差评估：计算恢复面形与真实面形之间的残差 $\epsilon(x, y) = \hat{h}(x, y) - h(x, y)$，输出峰谷误差 PV 与均方根误差 RMSE（单位：$\mathrm{nm}$）。

#### 2. 大致出来的视觉效果与图表（The Visual Effects）

最终在程序运行后，将生成包含 5 类诊断图表的综合评估面板：

1. **探测器干涉条纹图（Interferograms）**：
   - **零倾斜状态**：视野中呈现均匀亮暗场。
     - $d = 0$：全视场同相干涉，呈亮场；
     - $d = \lambda/4 \approx 158.2\,\mathrm{nm}$：往返程差改变 $\lambda/2$，全场瞬间翻转为**全暗场（黑夜）**；
     - $d = \lambda/2 \approx 316.4\,\mathrm{nm}$：往返程差改变 $\lambda$，全场再次回到**全亮场**。
   - **微倾斜状态（如 $0.1^\circ$）**：视野中出现排布致密的平行直条纹（空间载波）。当轴向位移 $d$ 逐渐增加时，可直观看到条纹整体横向“滑移”；当移动恰好为 $316.4\,\mathrm{nm}$ 时，条纹恰好滑移一个周期并与原位完全重合。
2. **四步相移多通道对比矩阵（Four-Step Mosaic / Polarized Channels）**：
   - 展现 $I_1, I_2, I_3, I_4$ 四幅灰度图。可以清晰看到相邻通道间条纹明暗位置平移了 $1/4$ 个条纹周期（$\pi/2$ 相移差）。
3. **包裹相位图（Wrapped Phase Map）**：
   - 呈现典型的黑到白循环锯齿条纹（值域 $[-\pi, +\pi]$），具有尖锐的阶跃边界。
4. **解包裹连续相位与三维重构形貌（Unwrapped Surface Map）**：
   - 锯齿跳变被完全修复拉平，展现出连续光滑的三维试样表面形貌。
5. **一维中心截线与纳米级残差图（1D Profile & Residual Error Map）**：
   - 真实面形曲线与恢复面形曲线高度贴合；
   - 给出纳米级残差曲线。在静态理想条件下残差接近 $0.00\,\mathrm{nm}$（浮点机理精度）；而在后续加入动态振动或曝光时间积分后，此处将立刻显现出波浪状的动态解调畸变波纹。

### 十二、2026-10-23 接纳 Codex 技术评审：三项物理纠偏与五天执行计划对齐

Codex 查阅了官方文档、Novak 2005 原文及项目基线，指出了原规划中的 3 处实质性物理/技术错误，并制定了切实可行的五天执行计划（见 `archive/antigravity/docs/handoff/2026-10-23-codex-review-opinions.md` 和 `2026-10-23-five-day-zemax-paper-study-plan.md`）。AI 全面确认并接纳以下技术修订：

#### 1. 三项核心技术纠偏与物理机理澄清

1. **探测器对象纠偏（Detector Surface $\to$ Detector Rectangle）**：
   - **错误指出**：原规划所写的 `Detector Surface` 在非顺序模式下仅支持非相干辐照度（Incoherent Irradiance），无法观察相干条纹；
   - **修正方案**：平面干涉条纹必须使用 **`Detector Rectangle`** 对象，并在探测器查看器中选择 **`Coherent Irradiance`**。同时，普通均匀玻璃 Cube 无法自动产生内部 50:50 分束面，需要明确构建两个棱镜拼接或指定内部对角面与镀膜（`I.50`）。
2. **偏振物理链路纠偏（补齐传感模块的关键第 3 块 QWP）**：
   - **错误指出**：原规划称“两臂各放一块 QWP，往返后直接得到正交圆偏振”，违背了偏振干涉原理；
   - **正确机理（严格对齐 Novak 2005 图 1 / 式 1）**：
     - 入射线偏振（调至对角线方向，使 p 与 s 等强）$\to$ PBS 分束为 p 光（透过）与 s 光（反射）；
     - 两臂各自放置一块光轴 $45^\circ$ 的 QWP：单程变为圆偏振，经镜面反射再次穿过 QWP，往返累积 $\lambda/2$ 延迟，出射为**正交线偏振**（p 变 s，s 变 p），实现 PBS 处的高效回光路由合束；
     - 合束后的正交线偏振，必须再经过**探测传感模块的第 3 块 QWP（快轴与偏振轴成 $45^\circ$）**，才转换为正交的正圆与反圆偏振光！
     - 正交圆偏振光射入 $0^\circ, 45^\circ, 90^\circ, 135^\circ$ 微偏振片阵列，才能根据检偏角产生严格的 $0, \pi/2, \pi, 3\pi/2$ 四步相移。若漏掉传感 QWP，微偏振片仅作振幅投影，无法产生相对相移！
3. **动态有限曝光物理机制纠偏（破除“无条件瞬时冻结”预设）**：
   - **错误指出**：原规划将同步法预设为“瞬时冻结无误差”，忽略了相机在单帧曝光时间 $T$ 内对连续振动积分的退化效应；
   - **正确物理模型**：同步法消除了帧间时间错位（$\Delta t$ 引起的相位漂移），但单帧曝光时间内仍受调制度因子 $C_T = \frac{1}{T}\int e^{i\phi_d(t)}dt$ 调制。当振动 $f=100\,\mathrm{Hz}, T=10\,\mathrm{ms}, H\approx 121.1\,\mathrm{nm}$ 时，贝塞尔调制因子 $J_0(4\pi H/\lambda) \approx 0$，条纹完全抹平消失！
   - **研究重构**：将课题重点调整为“在给定运动、曝光与采样条件下，顺序与同步方法各自的调制度、相位误差与有效极限范围”。
