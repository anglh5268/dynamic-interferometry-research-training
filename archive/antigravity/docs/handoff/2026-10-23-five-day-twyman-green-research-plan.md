# 动态干涉科研训练五天学习计划（优化修订版）

## 一、修改说明

本次修订严格依据实际科研训练需求（在 5 天内、每天约 3 小时完成有难度、可独立解释复现的练习，形成关键图表与简短说明用于和师姐交流），对原计划进行如下定向优化：

1. **规范学术措辞**：全面删除“保研突破”“杀手锏”“师姐一定刮目相看”“必然获得课题”等主观预设与夸大表述，采用严谨、客观的学术交流语调；保留主动沟通安排，但不预设导师反应。
2. **界定完成边界与图号核实**：第一天明确定义为“参考论文的简化泰曼–格林双臂模型”，不称为“师姐同款仪器”或“完整复现实际系统”；论文图号严格核准：Millerd 2005 泰曼–格林光路对应 **图 3**（图 1 为概念框架），Novak 2005 偏振干涉架构对应 **图 1**。
3. **收敛第三天工作量与精确表述**：复用已有 Jones 与四步相移 Python 程序，聚焦“正交线偏振 $\to$ 传感 QWP $\to$ 四方向检偏 $\to$ 相位恢复”；移去传感 QWP 的对照准确表述为“**不再满足所需的四个正交相移**”，不称完全无干涉；明确区分“四幅同位置理想通道”与“真实微偏振马赛克空间采样”。
4. **修正第四天曝光数学模型**：澄清贝塞尔调制度因子 $J_0(4\pi H/\lambda)$ 仅适用于**整数个完整振动周期**等特定工况；一般曝光严格使用光强的时间连续积分计算 $\bar{I}_k = \frac{1}{T}\int_{t_c-T/2}^{t_c+T/2} I_k(t)\mathrm{d}t$；显式引入振动初相 $\beta$；独立评估条纹调制度与解调相位误差，不预设二者必然同步恶化。
5. **精简参数扫描工况**：固定频率与振幅，仅扫描少量代表性曝光时间；时序比较中严格统一帧间隔 $\Delta t$、曝光窗 $T$（满足 $T \le \Delta t$）与参考真值中心时刻 $t_{\mathrm{ref}}$，杜绝时序逻辑矛盾。
6. **保留必要数值与极限检查**：包含解析周期预期比对、单项射线数/网格稳定性验证、静态极限（$H \to 0$）与短曝光极限（$T \to 0$）核验，不依赖纯截图肉眼定性评估。
7. **任务逐日落地**：明确每日“当天问题、需理解内容、具体操作/计算、时间分配、留存结果”；实体复杂偏振追迹、马赛克平铺与 API 自动化均划为提高项，不列为五天必经门槛。

### Day 1：参考论文建立简化泰曼–格林双臂模型

- **当天问题**：激光经分束器分成两路后，两臂光线在空间中如何走完全程，并在探测器上相遇形成相干条纹？
- **需理解内容**：
  - 结合 Millerd 2005 图 3 与 Novak 2005 图 1，理清准直光源、分束器、参考镜、测试镜及探测平面的几何拓扑；
  - 理解在非顺序模式（NSC）中，干涉条纹显示必须使用支持复振幅相干叠加的 `Detector Rectangle`，而非仅记录光强的 `Detector Surface`；
  - 明确普通玻璃立方体无内部对角面，需通过具有半透半反镀膜（`I.50`）的内部界面实现物理分光。
- **具体操作与计算**：
  1. 在 Zemax NSC 中建立工作波长 $\lambda = 632.8\,\mathrm{nm}$ 的准直激光源；
  2. 构造具有 $50:50$ 分束特性的内部界面；
  3. 放置参考镜 M1（固定单程约 $102\,\mathrm{mm}$）与测试镜 M2（正交臂单程约 $102\,\mathrm{mm}$）；
  4. 放置 `Detector Rectangle`（尺寸设为 $10\times 10\,\mathrm{mm}$，采样 $256\times 256$ 像素）；
  5. 分别检查两臂单路光斑能否正确落在探测器有效区域，开启相干数据（`Coherent Irradiance`），给测试镜微小倾角观察初步条纹。
- **时间分配（约 3 小时）**：
  - 30 分钟：对照论文图 3 与图 1 梳理双臂光路各元件功能与坐标；
  - 90 分钟：在 OpticStudio 中输入参数，建立光源、分束面、两平面镜与探测器；
  - 40 分钟：追迹分析光线，检查单臂覆盖与共同区域，核验 `Incoherent` 与 `Coherent` 视图差异；
  - 20 分钟：保存基准模型文件，导出 3D 布局图与初阶条纹图。
- **留下的结果**：
  - 标注元件名称与传播路径的 3D 光路图；
  - 一个能够正常打开、无遮挡报错的基准 NSC 模型文件；
  - 一幅可解释光路来源的基础相干条纹图。

### Day 2：镜面倾角与轴向位移的定量响应验证

- **当天问题**：改变测试镜的微小倾角或纳米级轴向位移，干涉条纹在周期和空间位置上会有什么定量变化？
- **需理解内容**：
  - 倾斜与空间载频：一束沿法线、另一束偏转 $2\theta$ 时，探测面空间条纹周期满足 $p = \frac{\lambda}{\sin(2\theta)}$；
  - 轴向微移与光程差：空气双程反射下 $\Delta\mathrm{OPD} \approx 2d$，引入相位差 $\Delta\phi = \frac{4\pi d}{\lambda}$；
  - $\lambda = 632.8\,\mathrm{nm}$ 条件下，$d = 158.2\,\mathrm{nm} (\lambda/4)$ 对应 $\pi$ 相位变化（明暗互换），$d = 316.4\,\mathrm{nm} (\lambda/2)$ 对应 $2\pi$ 周期复原；
  - 探测器像素尺寸与采样限制：全宽 $10\,\mathrm{mm}$、$256$ 像素对应像元尺寸约 $39\,\mu\mathrm{m}$，条纹周期须大于像元尺寸以避免欠采样。
- **具体操作与计算**：
  1. 固定其他参数，分别设置测试镜倾角 $\theta = 0.01^\circ, 0.02^\circ, 0.05^\circ$；
  2. 导出探测器中心一维强度剖面，拟合条纹周期并与解析值比对；
  3. 选取易于采样的倾角（如 $0.02^\circ$，理论周期约 $0.906\,\mathrm{mm}$，每周期约 $23.2$ 个像素），分别设置轴向位移 $d = 0\,\mathrm{nm}, 158.2\,\mathrm{nm}, 316.4\,\mathrm{nm}$，在固定显示尺度下核验条纹空间平移；
  4. 选取一个工况加倍分析光线数，验证拟合周期稳定、光线噪声不改变条纹基本分布。
- **时间分配（约 3 小时）**：
  - 30 分钟：推导双程光程差及倾斜载频解析式，算好目标数值；
  - 60 分钟：在软件中完成三组倾角的参数录入、追迹与剖面数据导出；
  - 60 分钟：完成三组微位移的追迹与图表导出，记录条纹平移量；
  - 30 分钟：整理倾角周期拟合表与位移响应图，完成稳定性核查记录。
- **留下的结果**：
  - 倾角—条纹周期对照表（包含理论值、仿真拟合值与相对偏差）；
  - 固定尺度下的三组微位移条纹剖面对照图；
  - 一项增加光线数后的数值稳定性对比记录。

### Day 3：正交线偏振到四相移的偏振链计算与对照

- **当天问题**：Novak 2005 论文中为什么需要多块波片与检偏器？合束后的传感 QWP 到底起什么作用？
- **需理解内容**：
  - 区分“两臂 QWP”与“探测端传感 QWP”的本质差异：两臂 QWP（快轴 $45^\circ$）通过双程往返将线偏振转为其正交线偏振（实现 PBS 处的高效路由）；合束后的正交线偏振必须穿过第 3 块传感 QWP（快轴与轴向成 $45^\circ$），才被转换为正交的正圆/反圆偏振；
  - 正交圆偏振光通过 $0^\circ, 45^\circ, 90^\circ, 135^\circ$ 检偏器时，几何旋转角直接映射为光波干涉的初相 $\delta_k = 0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}$；
  - 若移去传感 QWP，正交线偏振直接通过检偏器，仅发生振幅投影，不再满足解调所需的四个正交相移；
  - 区分“四幅同位置理想通道”与“真实微偏振阵列（MPA）像素马赛克采样”。
- **具体操作与计算**：
  1. 复用原工程中的 Jones 矩阵程序，输入正交线偏振场，加入传感 QWP 传输矩阵，随后投影到 4 个检偏方向；
  2. 生成理想四相移干涉图，利用四步相移算法求解包裹相位并恢复面形，验证算法闭环；
  3. 进行对照计算：在计算链中移去传感 QWP，重新提取相位，观察四通道相对相位关系为何被破坏；
  4. 记录有无传感 QWP 两种情况下四通道相位的数学表达式。
- **时间分配（约 3 小时）**：
  - 40 分钟：精读 Novak 2005 §2–3 及式 (1)，写出各段 Jones 向量与传输矩阵；
  - 60 分钟：在已有 Python 脚本中串联传感 QWP 与四通道检偏投影，生成四幅图；
  - 50 分钟：运行相位解调，完成移去传感 QWP 的错误对照计算；
  - 30 分钟：整理偏振链路原理示意图、四相移图与对照结论。
- **留下的结果**：
  - 简明偏振状态演化流程图（标明各节点偏振态）；
  - 正常四通道相移干涉图与恢复相位图；
  - 移去传感 QWP 导致四相移失效的对比说明与计算数据。

### Day 4：机械微振动与有限曝光时间积分影响

- **当天问题**：在正弦机械振动下，相机单帧曝光时间内的连续运动会对干涉条纹对比度及解调相位带来什么影响？
- **需理解内容**：
  - 同步采集消除了多帧之间的时间错位，但快门开启的曝光时间 $T$ 内部，运动仍会被连续积分：
    $$\bar{I}_k = \frac{1}{T}\int_{t_c - T/2}^{t_c + T/2} \left\{ A + B \cos\left[ \phi_0 + \frac{4\pi}{\lambda} H\sin(2\pi f t + \beta) + \delta_k \right] \right\} \mathrm{d}t$$
  - 贝塞尔因子调制度 $J_0(4\pi H/\lambda)$ 仅在**曝光时间为振动周期的整数倍（$T = m/f$）**等特定对称条件下严格成立；任意曝光时间须通过数值积分计算；
  - 调制度下降（条纹对比度变差）与相位解调误差（恢复形貌偏差）是两个相关但不等同的物理指标，需分别评估；
  - 时序逻辑界定：单帧曝光时间 $T$ 须小于等于顺序法的帧间隔 $\Delta t$（即 $T \le \Delta t$），真值参考点统一设为时间中心时刻 $t_c$。
- **具体操作与计算**：
  1. 在 Python 动态程序副本中建立时间积分模块（每个曝光窗口采用足够的时间采样点平均）；
  2. 固定振动参数：$f = 100\,\mathrm{Hz}$，振动幅度 $H = 50\,\mathrm{nm}$，初相 $\beta = \pi/4$，顺序采集帧间隔设为 $\Delta t = 2\,\mathrm{ms}$；
  3. 扫描曝光时间 $T$（选取 $T = 0.1, 0.5, 1.0, 2.0\,\mathrm{ms}$），计算同步与顺序采集的条纹对比度及相位恢复 RMSE；
  4. 选定一个特定振动幅度（如 $H = 120\,\mathrm{nm}$），单点核验接近整周期（$T = 10\,\mathrm{ms}$）时调制度大幅衰减的工况，检验短曝光极限（$T \to 0$）与静态极限（$H \to 0$）数值收敛性。
- **时间分配（约 3 小时）**：
  - 30 分钟：推导时间积分形式，理清曝光时间 $T$、帧间隔 $\Delta t$ 与振动周期的相对关系；
  - 70 分钟：完善时间连续数值积分代码，完成固定振幅下的 4 个曝光时间点计算；
  - 50 分钟：提取条纹调制度与相位恢复残差曲线，运行极限条件核验；
  - 30 分钟：整理调制度衰减曲线、误差对比图与物理原因说明。
- **留下的结果**：
  - 顺序法与同步法在不同曝光时间下的干涉图与恢复残差对比；
  - 曝光时间对条纹调制度及相位恢复误差的影响曲线；
  - 静态极限与数值采样稳定性核查说明。
