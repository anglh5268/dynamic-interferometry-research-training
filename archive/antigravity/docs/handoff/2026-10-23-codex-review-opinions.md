## 二、必须先修正的问题

### 1. 阶段一的探测器类型选错

路线第 71 行及简报把 `Detector Surface` 作为相干条纹探测器。官方说明中，Detector Surface 只记录非相干辐照度；用于本练习的平面矩形相干探测器应选 **Detector Rectangle**，再在 Detector Viewer 选择 Coherent Irradiance。

开启相干显示之前，要有实际 Analysis Ray Trace 数据。NSC 3D Layout 中的显示光线与分析追迹是不同用途。分束还需要正确界面和镀膜，以及 Use Polarization、Split NSC Rays 设置。

依据：[Detectors used in illumination design](https://optics.ansys.com/hc/en-us/articles/42661774340243-Detectors-used-in-illumination-design)。官方通用文档用于确认机制；2024 的具体界面名称在首次操作时按实际界面核对。

### 2. 阶段二漏了一块关键波片，往返偏振态写反

路线第 45 行、第 80 行声称两臂 QWP 往返后直接得到正交圆偏振，这是错误的。按 Novak 2005 图 1 所述的理想链路：

1. 入射线偏振通过半波片等方式调节 p/s 分量，使 PBS 分出的两臂都有光，并按返回功率平衡强度。输入只有 p 或只有 s 时，理想 PBS 不会自动给出两束等强光。
2. 两臂的 QWP 把各自入射线偏振转换为圆偏振；镜面反射后再通过各自 QWP，返回的是与去程正交的**线偏振**，用于 PBS 的回光路由。
3. 合束后，需要探测模块中的**另一块 QWP**，把正交线偏振转换成正交圆偏振，再由微偏振片方向产生相移。

因此，原文省掉的是相位传感模块的 QWP。两臂波片的“45°”也必须说明相对于哪条局部偏振轴，不能在不同传播方向下盲目填相同全局欧拉角。反射和 s/p 坐标变换需要一起进入 Jones 链。

两个正交线偏振只经过四个不同方向的线检偏器，不会自动获得所需的正交四相移。传感 QWP 是机制的一部分。

直接依据：[Novak 等 2005 作者机构公开全文，§2 和 §3、图 1、式（1）](https://wp.optics.arizona.edu/jcwyant/wp-content/uploads/sites/13/2016/08/MicropolarizerPSI.pdf)。项目原有 Millerd 带读笔记也已区分两臂 QWP 与掩膜前 QWP。

### 3. 真实微偏振马赛克不能当作四幅完整同位置图

每个 2×2 单元的四个方向对应四个不同像素位置；整个探测面需平铺许多单元。四个方向、四幅同位置完整图，以及真实 2×2 马赛克是三个不同层次。

建议先在相同坐标上验证理想四个检偏通道的相移与符号，再加入像素面积积分、光学带宽/PSF、马赛克采样和解调邻域。NSC 中逐像素建立大量独立微偏振元件不应成为本阶段前置任务；也不能用几何光线把纳米线栅的电磁行为宣称为已精确模拟。

优先用 NSC 核对宏观 PBS/波片/合束链，用已有 Jones 与 Python 模型处理阵列的有效偏振投影和空间采样。必要时才另研究微结构或扩展元件模型。

### 4. 有限曝光与“瞬时冻结”不能同时无条件成立

路线第 52 行及阶段三把顺序法崩溃、同步法瞬时冻结作为预期结果，属于结论先行。同步解决的是通道之间的采集时刻不一致，曝光期间的运动仍会被积分。

对理想四通道，一幅图应按同一曝光窗计算：

\[
\bar I_k(x,y)=\frac1T\int_{t_c-T/2}^{t_c+T/2}
\{A+B\cos[\phi_0(x,y)+\phi_d(t)+\delta_k]\}\,dt.
\]

定义曝光的复调制因子

\[
C_T=\frac1T\int_{t_c-T/2}^{t_c+T/2}e^{i\phi_d(t)}dt.
\]

理想解调得到的调制幅度和相位由 \(|C_T|\) 与 \(\arg C_T\) 决定；它们不必等于中心时刻的幅度和相位。把瞬时复电场跨时刻相干叠加再平方，与对探测光强积分是不同运算，不能混用。

**本次独立计算的反例：**λ=632.8 nm，d(t)=H sin(2πft)，f=100 Hz，T=10 ms，曝光覆盖一个完整振动周期。这些参数都落在新路线提出的范围内。对相位指数进行等时间周期求和，1024 点与 4096 点所得结果一致：

| H / nm | 复调制因子实部 | 解释 |
|---:|---:|---|
| 0 | 1 | 静态 |
| 50 | 0.768306 | 调制度下降 |
| 121.098896 | 约 0，数值残差约 10⁻¹⁶ | 理想同步条纹近乎消失，相位不可可靠恢复 |
| 200 | −0.398867 | 调制项反号，不能当作中心时刻相位无误差 |

以上为本评审的理想解析模型数值检查，不是 Zemax 追迹或实验结果。这个整周期例子的系数也可写为 J₀(4πH/λ)。

应把研究问题改为：**顺序采集与同步采集在有限曝光、指定运动和采样条件下的误差、调制度及有效像素范围是什么？**同时注明 Novak 论文的时间冻结论述以采集时间远短于相关振动时间尺度为条件。

顺序比较还需指定帧间隔 Δt、相移实现方式和曝光窗。不能把原基线的 Δt=1 ms 不加说明地与 T=10 ms 搭配成同一相机四个互不重叠的顺序曝光。

## 三、阶段一还需要补足的工程定义

### 分束立方体并非给普通 Cube 填材料就完成

一个普通均匀玻璃块不会凭空出现可镀膜的内部对角面。需要明确几何对象、分束界面、对应 Face 和双程中各次反射/透射。官方例子以两个相邻棱镜构造立方体并在内界面分光，外表面则单独处理。

可先用理想 50:50 分束界面降低调试难度，再替换为完整立方体；若目标就是学习实体棱镜，则直接沿官方样例确认该内部界面的定义。还要记录镀膜复振幅/相位，不能把 50:50 功率比当作两路相位已确定。

官方依据：[Exploring Non-Sequential Mode，Beam splitting](https://optics.ansys.com/hc/en-us/articles/42661670424851-Exploring-Non-Sequential-Mode-in-OpticStudio)。

### 坐标与方向不能只列位置

M2 放在 X=102 mm 时，其法线也要对准该臂传播方向。探测器同样需指定法线、出射端口和局部 XY 轴。Z=−102 mm 是否是所需探测端取决于所选分束面朝向，不应提前写死。要区分镜面相对分束中心的距离、到棱镜外表面的空气距离和累计光程。

同一相干源分出的两路是清晰基线。最初关闭不必要的外表面寄生反射，正确设置偏振与分光；在无相干交叉项的数据中检查两臂功率和空间重叠，再看相干条纹。

### 相干功率归一化会影响验收

Detector Rectangle 的 **Normalize Coherent Power** 不可忽略。官方明确指出，多条纹与整体单个亮/暗场的适用设置不同，光线模型还有相干功率计算局限。因此：

- 记录归一化和固定显示尺度，不能用逐图自动拉伸的截图判断真实亮暗反转；
- 对零倾角的单一亮/暗场，按官方建议核对关闭该归一化的情形；
- 不以单端口绝对功率的简单相加，宣称已经完整验证了双端口干涉的能量重分配。

依据：[Detector Rectangle Object，coherent power discussion](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v261/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Detector_Rectangle_Object.html)。

NSC 相干探测能模拟光程导致的条纹，但它仍然有光线模型的适用边界；不能把“3D 实体”升级为“全波电磁模型”或真实相机。数值光线采样噪声也不等于物理光子散粒噪声。

## 四、原参数是否合适

| 参数 | 评审意见 |
|---|---|
| 632.8 nm | 合适，便于对接已有程序与所读 He–Ne 示例；属于模型选择，真实光源参数待实验条件确定 |
| 102 mm | 可作为教学几何长度，不是课题必需值；须说明从哪个界面量起，玻璃和空气段分别计入 |
| 0.1° 镜面倾角 | 可用，但只是与既有验证衔接的一个工况，可先用更稀疏条纹调通；不要求为了沿用历史数值保留它 |
| p≈181.3 μm | 一束沿探测面法线、另一束在相应平面内偏转 0.2°、同介质且无额外成像倍率时成立；不是任意折叠光路的通式 |
| f=10–500 Hz、H=10–200 nm、T=1–10 ms | 可作探索范围，不是已确认的实验规格或保证抗振区间；应按 fT、4πH/λ 和帧间相位推进量组织扫描 |

一般平面波在共同探测面上满足切向波矢差关系：

\[
\mathbf f_\parallel=(\mathbf k_{t,\parallel}-\mathbf k_{r,\parallel})/(2\pi).
\]

因此条纹沿探测器哪个方向变化要由实际局部坐标决定，不能看到 Tilt X 就直接命名为 fₓ。对一个轴上波与一个偏转 0.2° 的波，本次复算 p=181.284 μm。

256×256 本身不足以定义采样。若探测器全宽为 10 mm，则每周期约 4.64 像素；若全宽为 20 mm，只有约 2.32 像素。建议以每周期约 6–10 像素作为初始工程选择，并做收敛检查；例如全宽 12 mm、512 像素时约 7.73 像素/周期。该建议不是普遍采样定理或固定验收阈值。需同时保证足够的每像素分析光线数。

5 mm Gaussian 半径也不是严格的 10 mm 硬孔径，要写清高斯半径定义、截断和探测区。真实马赛克每类像素的间隔还会增大，不能照搬完整图的采样条件。

ΔOPD≈2d、Δφ≈4πd/λ 适用于此处空气中近法向双程小位移；更一般的情况需要折射率、入射角和机械位移方向。原文称“严格映射”应补上条件。158.2 nm 和 316.4 nm 的量级在这些条件下正确；无空间条纹时应称整体亮暗/强度周期变化，不能一律称条纹滑移。

验收的“严格一致”应改为在明确采样、射线数和拟合不确定度下收敛到解析值，记录残差；不要凭截图量条纹宽度作为精度结果。

## 五、建议采用的修订路线

### 阶段一保留：一个最小 NSC 标量双臂模型

**近期唯一交付：一个能追踪两条返回路径、显示可解释直条纹并通过周期/位移检查的模型。**暂不加入 PBS、微偏振阵列或 API。

执行顺序：

1. AI 先准备路径图、对象与位置/朝向表，并核对可分光界面的构造；用户理解元件功能后再输入。
2. 用同一个准直源、理想分光、两平面镜和 Detector Rectangle 完成几何返回。分别检查单臂照明和共同探测区。
3. 开启适当相干数据，读取固定尺度直条纹剖面；用已知探测器尺寸拟合周期，改变射线数/网格验证结果稳定。
4. 在选定归一化与相位基准下检查 λ/4、λ/2 轴向位移，并注明单位换算为 0.0001582 mm、0.0003164 mm。数据读取精度应足够，不能只看截断表格。
5. 保存一个基准模型、一张标注条件的剖面对照和短结果说明，即可进入下一阶段。

官方 `Samples\Non-sequential\Coherence\A Simple Interferometer.zmx` 可作设置参照，但它包含两个分束器，不应把该样例本身叫作已复现目标泰曼–格林系统。先按 2024 安装中的实际样例位置查找一次，不为找样例耗掉一节课。

### 阶段二拆成两步：宏观偏振链→真实空间采样

**2A：**输入偏振/功率平衡→PBS→两臂 QWP 往返→合束→传感 QWP→理想四方向检偏。先核对几个关键位置的 Jones/Stokes 状态，以及四通道相移、强度关系和解调符号。四个同位置理想通道是有效性基线，不称为真实马赛克。

**2B：**用 Python 在共同网格的场/强度上加入像素积分与 2×2 平铺，配合必要的带宽/成像条件，研究空间梯度造成的误差。保留完整图和马赛克解调各自的有效分辨率。无需逐像素建立大量 NSC 实体。

### 阶段三调整：先动态与曝光，API 并行轻量验证

不要把完整 NSC+MPA+API 自动化全部完成作为研究动态误差的前提。

- API 先做很小的功能验证：连接当前版本、改一个镜面位置、清空探测器、追迹并导出一幅原始矩阵，恢复基准。先完成静态参数—图像对应，不宣称连续机械动态求解。
- 对刚性平面镜纯轴向纳米振动，优先使用已验证的双程相位灵敏度复用静态场，运行已有动态程序和新增曝光积分；用少数 Zemax 位姿点检查该近似。
- 如果倾角、光斑位置、遮挡、像差或偏振也随时间改变，再按需要增加 API 几何采样，检查插值和时间积分收敛，不在每一个高密度时间点无条件追全模型。
- 曝光在 Python 中按各时刻光强积分。每个 NSC 快照先清空相干累计；不要让不同时间点的场在同一个探测器中相干累积，冒充曝光。
- 比较统一中心时刻真值；报告圆周相位误差、整体偏差、形状误差、调制度和有效区域。若比较噪声，另外统一光子预算、曝光和增益；理想归一化图不能代表真实同步通道没有分光损耗。
- 局部动态形变可作为后续增量；不要仅以刚性整体振动加去 piston 的误差，代表动态面形恢复能力。

## 六、科研表述与推进判断

删除或降格“论文级核心创新”“高质量期刊论文数据”“完全满足顶级论文要求”等先验承诺。新环境和 API 是工具，参数扫描是方法，能否形成研究贡献要看新问题、已有方法比较、误差机制和独立验证。

旧结果 RMSE≈0.2637 rad≈13.28 nm 是一个特定理想动态工况，不能称为顺序法普遍崩溃；同步≈10⁻¹⁶ rad 是理想模型数值自洽，不是仪器准确度。

同一强度余弦形式并不保证 NSC 与简化 Python 物理模型等价。振幅、光程、偏振、像素映射、空间带宽、相干性和曝光条件必须一致，才可作对应比较。Zemax 本身也有相干/物理光学能力，所以不宜写成“Zemax 只几何、Python 才波动”；合理分工是用各自适合的能力验证不同层次。

缺少实际装置图、器件清单、相机和原始数据时，632.8 nm、102 mm 及当前器件组合仍是学习模型，不能宣称与课题组实际仪器“完全契合”。对齐老师或师姐的装置条件可以在阶段一结果之后明确，不阻塞当前基础练习。

**下一步建议：修正上述硬错误后，开始阶段一最小 NSC 双臂基线。第一份成果是一幅经几何、采样及相位检查的条纹结果；第二份成果是正确的理想四通道偏振链。动态研究复用已有程序，与轻量 API 验证并行推进。**
