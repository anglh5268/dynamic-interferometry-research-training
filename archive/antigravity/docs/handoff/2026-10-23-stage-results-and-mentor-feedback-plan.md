# 围绕科研训练与指定论文的学习安排

更新：2026-10-23，按用户补充简化。目标是结合师姐给的论文，边理解、边动手，留下一些可以交流的小成果。以此安排替代此前偏正式的成果包和汇报要求。同日技术评审中的物理纠错仍保留。

> 具体执行安排见 [五天学习计划](2026-10-23-five-day-zemax-paper-study-plan.md)：按每天约 3 小时安排，覆盖双臂模型、定量对照、偏振四通道、动态与曝光及结果整理。

## 1. 先把论文里的光路看明白

从已带读的 Novak/Millerd 动态干涉论文出发，解释光源、分束器、参考镜、测试镜和探测部分分别有什么作用，光怎样走。

接着在 Zemax 里搭一个简化的双臂模型，先观察分光、反射、合束和条纹。每次只讲当前用到的元件和参数，不要求一开始完整复现论文仪器。

留下：一张标注过的光路图、几张实际结果，以及自己对光路的简短解释。计划图与实际追迹结果分别注明。

## 2. 改一个参数，理解一种现象

例如移动一点镜子或改变一点倾角，先解释会发生什么，再操作观察。结果确认后就推进，不反复做同一验证。

留下：一组前后对照图，说明改了什么、发生了什么，以及与论文中的哪段原理相关。解析计算、Zemax 结果与 Python 结果标明来源。

## 3. 接回论文中的偏振和动态问题

结合师姐给的论文，逐步理解为什么使用波片、偏振片，以及为什么同步采集有助于动态测量。需要时用已有 Python 程序辅助观察振动或曝光的影响，不从头重做已有程序。

留下：一两组能解释的图和几个具体疑问。更深入的误差分析，等实际理解与师姐反馈后再决定。

## 与师姐交流

完成一个小练习、能够解释结果后，就可以拿几张图和简短说明交流：自己读懂了哪一部分、动手做了什么、还有什么不明白。

不固定要求 PPT 页数、正式报告或创新结论，也不等待整个系统学完。优先请师姐判断理解是否正确、接下来适合练哪一部分。
